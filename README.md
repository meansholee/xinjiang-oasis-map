# 西域绿洲 · 时空舆图

> 以**时间轴**驱动，按 15 个历史朝代（西汉 → 现代）展示新疆绿洲城镇的时空演变。
> 鎏金绢本手绘风底图 + 真实经纬度精确定位，可点击城镇 / 古迹查看历史名片。

一个纯前端、零依赖、可离线运行的中国新疆历史地理可视化 Demo。基于真实 GIS 数据与新疆行政边界，用 D3 墨卡托投影将 286 个历史城镇点、365 处文物保护单位按朝代分层钉在青绿山水风的舆图上。

## ✨ 特性

- **真实地理定位**：城镇点、古迹点全部使用真实经纬度，经 D3 `geoMercator` 投影精确落位（非示意坐标）。
- **真实新疆边界**：底图轮廓取自权威行政边界数据（省界 + 24 个地州），描金双线，盆地 / 山脉 / 水系按真实地理渲染。
- **时间轴演变**：15 个朝代滑块切换 + 自动漫游播放，点位随朝代淡入淡出。
- **可交互名片**：hover 显名，click 弹出右侧历史名片（含经纬度、舆地数据、古籍载录）。
- **国风美术**：鎏金绢本底、流沙波浪、青金河流、黛蓝雪山、宣纸纹理、朱红印章题跋。
- **纯离线**：数据、地图库、字体全部本地化，**双击 `index.html` 即可运行**，无需联网、无需服务器。

## 🚀 运行方式

**方式一（推荐）**：直接双击 `index.html` 用浏览器打开即可。

**方式二**：本地服务器（如需）

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

```
.

```

## 📊 数据说明

| 文件 | 内容 | 字段 |
|------|------|------|
| `data/towns.json` | 286 个城镇治所点 | `id / name / era / eraIndex / lng / lat` |
| `data/relics.json` | 365 处文物保护单位 | `name / era / type / addr / city / county / lng / lat` |

数据按 15 个朝代分层：西汉、东汉、三国、西晋、东晋、南北朝、隋、唐、五代十国、辽北宋、金南宋、元、明、清、现代。

## 🛠 技术栈

纯前端三件套 + [D3.js](https://d3js.org/) v7。Canvas 绘制手绘底图与地形，D3 `geoMercator`（手动平面 fit）做经纬度→像素投影，SVG 承载可交互点位。
